# LinguaFlow AI

AI-powered multilingual translation assistant built using React and FastAPI.

## Features

- 🌐 Auto language selection
- 🔄 Language swap
- 📋 Copy translation
- 🔊 Text-to-speech
- 📥 Download translation
- 🕒 Translation history
- 🎨 Responsive UI

## Tech Stack

- React
- FastAPI
- Deep Translator
- Axios
